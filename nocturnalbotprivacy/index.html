Nocturnal Bot — Privacy Policy

Privacy Policy

Last Updated: September 2026

Nocturnal Bot collects minimal data required to provide core functionalities.

1. Data We Collect

  • Discord User IDs: Stored to manage user introductions, internal gamble levels, and DM opt-out preferences.
  • Discord Guild (Server) IDs: Stored to save per-server counting states and configuration settings.
  • Discord Channel & Role IDs: Stored to associate server settings configured via /setup.

2. How Data is Used

Stored data is used strictly for bot functionality (e.g., tracking who counted last, managing gamble tiers, and syncing roles). We do not sell, share, or monetize user data. We don't even know how.

3. Data Retention & Deletion

Data remains saved as long as the Bot is in your server or until a server reset occurs. You can request manual removal of your stored data by contacting the developer or removing the Bot from your server. You can do this by either using the messaging feature on noctulla.xyz or by contacting "noctulla" via discord.
